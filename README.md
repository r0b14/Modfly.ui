# 📐 Modfy UI

> **Components built for learning.**

O **Modfy UI** é uma biblioteca de componentes de interface construída com **React**, **TypeScript** e **Tailwind CSS**. Ela foi desenvolvida para acelerar a criação de plataformas educacionais (como o AVAMEC), permitindo que a interface cresça e se adapte conforme novos cursos são produzidos.

---

## 🎨 Estética e Visão
Baseada em uma estética **neo-retro pixel**, a Modfy UI une a nostalgia dos sistemas clássicos com a robustez da engenharia de software moderna praticada no **CIn-UFPE**.

## 🛠️ Stack Técnica
- **Framework:** React 19
- **Estilização:** Tailwind CSS
- **Componentes Primitivos:** Radix UI
- **Monorepo:** pnpm + Turborepo
- **Documentação:** Next.js + MDX (Hospedado na Vercel)

## 📦 Instalação (CLI)
Em breve você poderá adicionar componentes diretamente ao seu projeto:
```bash
npx modfy@latest add button
```
