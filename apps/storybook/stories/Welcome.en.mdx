# Modfly UI: component lab

Try real library variants, adjust properties in **Controls** and check behavior before composing a lesson.

- **Core:** 42 public components in 39 groups, distributed with CSS, types and assets.
- **AVAMEC:** seven activity formats. The demonstration uses memory and sends no data to the platform.
- **CLI:** copy editable code with `modfly`. Version 1.1.0 is in preparation for npm publication.

Stories preserve Portuguese course examples. Component and control names are the identifiers used in code.

[English documentation](https://modfly.design/en) · [Ler em português](?path=/docs/welcome-portugues--docs)

## How to explore

Choose a component in navigation, open a variant and adjust available properties. Test keyboard use and a smaller viewport too. Public documentation explains installation, APIs and composition; this lab focuses on visual experimentation.

## Customization and integration

Custom colors and dimensions must remain readable. HTML content must be sanitized by the application. External players and the real AVAMEC connection require validation in the course environment.
