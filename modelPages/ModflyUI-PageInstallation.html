Getting Started · 02 of 04

Up and running in under a minute.

O Modfy UI é distribuído como um pacote npm tree-shakeable. Esta página cobre instalação, configuração mínima do Tailwind e o primeiro <UnityBanner /> renderizando na tela.

Version 0.1.0
Updated 27 May 2026
Read time ~6 min
Status stable

# 01 · Pré-requisitos Before you install

Modfy UI roda em qualquer aplicação React 18+ com Tailwind. Não há dependências escondidas — a lib é peer-dependency-only em react, react-dom e tailwindcss.

Dependência Versão mínima Status Notas
node 18.18+ supported 20.x recomendado
react ^18.2.0 supported peer dep
tailwindcss ^3.4.0 supported v4 em alpha
typescript ^5.0 optional tipos incluídos
react-router — not required componentes recebem callbacks
Tip · pnpm é o gerenciador oficial

O monorepo do Modfy usa pnpm + Turborepo. Os exemplos assumem pnpm, mas npm e yarn funcionam igual — só troque o comando.

# 02 · Instalação Install the package

Escolha seu package manager. O pacote é menor que 80kb gzipped e suporta ESM e CJS — sem configuração extra de bundler.

$ pnpm add @modfy/ui
$ npm install @modfy/ui
$ yarn add @modfy/ui
$ bun add @modfy/ui

Optional: instalar o pacote AVAMEC

Se você está escrevendo cursos para a plataforma AVAMEC do MEC, instale também o sub-pacote dedicado. Ele expõe QuestionOption, QuestionMultipleAnswer, etc., já integrados com a BridgeRestApi.

terminal
$ pnpm add @modfy/ui-avamec

# 03 · Setup Configure your project

Três passos. Apenas o 2 é não-óbvio — sem ele, as classes Tailwind da lib não aparecem no bundle final do seu projeto.

Import the global styles

No seu arquivo de entrada (main.tsx, _app.tsx ou equivalente), importe os estilos base. Eles incluem reset, fontes e tokens.

src / main.tsx 
import '@modfy/ui/styles.css'
import React from 'react'
import { createRoot } from 'react-dom/client'
import App from './App'

createRoot(document.getElementById('root')!).render(<App />)

Update your Tailwind config

Adicione o caminho dos componentes ao array content para que o JIT do Tailwind veja as classes usadas dentro do @modfy/ui.

tailwind.config.ts 
import type { Config } from 'tailwindcss'

export default {
  content: [
    './src/**/*.{ts,tsx}',
    // 👇 obrigatório para classes da lib
    './node_modules/@modfy/ui/dist/**/*.js',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
} satisfies Config
Atenção · esquecer este passo é o erro #1

Se você instalar o pacote e os componentes aparecerem sem estilos, 100% das vezes é o content do Tailwind faltando. Verifique o caminho em node_modules/@modfy/ui/dist.

Render your first component

Cole o trecho abaixo numa página qualquer. Você deve ver o banner roxo da unidade renderizando na tela.

src / pages / HelloModfy.tsx 
import { UnityBanner } from '@modfy/ui'

export default function HelloModfy() {
  return (
    <UnityBanner
      number={1}
      title="Hello, Modfy"
      subtitle="Componentes prontos para construir cursos."
    />
  )
}
Pro tip · imports tree-shakeable

Todos os componentes são exportados individualmente. Use import { UnityBanner } from '@modfy/ui' — o bundler descarta o resto. Sem barrel files quebrando o tree-shake.

# 04 · Verificação You should see this

Rode o seu dev server (pnpm dev, npm run dev, etc). Se tudo estiver no lugar, o banner abaixo renderiza com o gradiente roxo característico:

UNIDADE
01.
Hello, Modfy
COMPONENTES PRONTOS PARA CONSTRUIR CURSOS.
↑ <UnityBanner /> renderizado
Não está vendo nada?

Se o componente aparece como texto cru ou sem estilo, abra o DevTools e procure pelas classes do Tailwind no HTML. Se elas estão lá mas não têm efeito → seu content está errado. Se nem estão → o import do CSS global está faltando.

Ainda travado? Abra uma issue no GitHub com seu package.json e tailwind.config.

# 05 · O que vem a seguir Where to go from here

Você tem o ambiente pronto. Algumas direções recomendadas a partir daqui:

  • Tailwind setup — customização avançada do tailwind.config, extensão da paleta e fontes customizadas.
  • Theming — como sobrescrever as 6 cores base da lib via CSS variables sem ejetar componentes.
  • Components — catálogo completo dos 38+ componentes organizados por Atoms / Molecules / Organisms / Templates.
  • @modfy/ui-avamec — instale e configure o sub-pacote para integração com a BridgeRestApi do AVAMEC.
