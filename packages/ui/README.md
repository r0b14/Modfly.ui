# @modfly/ui

Componentes React e TypeScript para cursos. Versão em preparação: 1.1.0.

```tsx
import { Citation } from '@modfly/ui';
import '@modfly/ui/styles.css';
export function Aula() { return <Citation title="Para refletir" text="Aprender exige prática." />; }
```

React 18.2 ou 19. Saídas ESM, CommonJS e tipos TypeScript. CSS compilado incluído; não é necessário configurar Tailwind para o primeiro uso. Alguns componentes usam Emotion internamente.

[Documentação](https://modfly.design) · [Código e status da release](https://github.com/r0b14/Modfly.ui) · MIT.
